MY LOVE — ADVANCED BIRTHDAY SURPRISE
====================================
Open index.html to preview the website. The folder includes your uploaded photos and video, a cinematic invitation artwork, responsive styling, animated effects, a birthday letter, gallery, video memory, wish interaction and a QR generator.

BACKGROUND SONG — IMPORTANT
The soundtrack code is already configured for:
  assets/love-someone.mp3

I cannot include or fetch a copyrighted commercial song file. Please place your own legally obtained MP3 copy of "Love Someone" by Lukas Graham in the assets folder and name it exactly:
  love-someone.mp3

Then the song will start when the visitor presses "Open your surprise". Browsers generally block autoplay with sound until a person interacts with the page, so the first tap starts the music. The floating music control lets the visitor pause or resume it.

QR CODE SETUP
1. Publish the entire folder using Netlify Drop: https://app.netlify.com/drop
2. Copy the public URL Netlify gives you.
3. Open qr-generator.html in a browser.
4. Paste the public URL, create the QR code, then download it.
5. Test the QR code with another phone.

KEEP THE FILE STRUCTURE
Keep index.html, style.css, script.js, qr-generator.html and the assets folder together.
Do not rename or move the assets.
The QR generator uses an online QR library and needs internet access.
